# Seguridad

No publiques contraseñas, tokens, certificados, bases de datos ni respaldos en incidencias, commits o Releases. Usa exclusivamente datos ficticios para reproducir errores.

Si encuentras una vulnerabilidad, informa al propietario por un canal privado acordado. No compartas datos de clientes en una incidencia pública. El almacenamiento local y las copias de seguridad requieren protección del equipo y del medio donde se guardan.

La página central requiere su propia configuración por negocio. Las credenciales del dueño, las de las sucursales y las de Cloudflare tienen finalidades diferentes; no las sustituyas entre sí.

Este repositorio no incluye claves de producción. Si se filtra una clave, revócala y reemplázala: borrarla del archivo actual no la elimina del historial de Git.
